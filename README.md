## このリポジトリの運用ルール

- 学習セッションの最後に、その日の内容を1ファイルにまとめる
- ファイル名は `YYYY-MM-DD_テーマ.md` の形式
- 各ファイルは「学んだこと / つまずいた点 / 次回やること」の3項目で構成する
- 完璧な文章より、継続することを優先する
