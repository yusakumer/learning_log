# 01 配列と条件分岐：合格者を数える

## お題

点数が入った配列から、60点以上の人数を数えて表示してください。

- 点数は次の配列を使います。
- 配列の要素を順番に調べ、60点以上なら人数を1増やします。
- 最後に指定の形式で人数を表示します。

## 入力例

```javascript
const scores = [72, 58, 90, 64, 41];
```

この問題では標準入力は使いません。上の配列をプログラム内に用意してください。

## 期待する出力例

```text
合格者: 3人
```

## 実行方法

この問題フォルダで次を実行します。

```bash
node answer.js
```

## ヒント

- `for...of` を使うと、配列の値を1つずつ取り出せます。
- 条件分岐には `if` を使います。
- 人数を数える変数は最初に `0` にしておきます。
