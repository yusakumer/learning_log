# 02 filterで偶数を取り出す

## お題

数値の配列から偶数だけを取り出し、指定の形式で表示してください。

- 元の配列は変更せず、新しい配列を作ります。
- 数値の順番は元の配列と同じにします。

## 入力例

```javascript
const numbers = [7, 2, 5, 8, 3, 4];
```

この問題では標準入力は使いません。上の配列をプログラム内に用意してください。

## 期待する出力例

```text
偶数: 2, 8, 4
```

## 実行方法

この問題フォルダで次を実行します。

```bash
node answer.js
```

## ヒント

- `filter` は、条件を満たす要素だけを集めた新しい配列を返します。
- `number % 2 === 0` なら偶数です。
- `join(", ")` で配列の値をカンマとスペースでつなげられます。
