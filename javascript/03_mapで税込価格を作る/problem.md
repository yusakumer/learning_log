# 03 mapで税込価格を作る

## お題

税抜き価格の配列から、消費税10%を加えた税込価格の配列を作り、指定の形式で表示してください。

- 元の配列は変更しません。
- `map` を使って、各価格を税込価格に変換します。
- 価格の順番は元の配列と同じにします。
- 今回の入力では、税込価格はすべて整数になります。

## 入力例

```javascript
const prices = [100, 250, 80];
```

この問題では標準入力は使いません。上の配列をプログラム内に用意してください。

## 期待する出力例

```text
税込価格: 110, 275, 88
```

## 実行方法

この問題フォルダで次を実行します。

```bash
node answer.js
```

## ヒント

- `map` は配列の各要素を変換し、新しい配列を返します。
- 税込価格は税抜き価格に `1.1` を掛けて求められます。
- 配列を指定の形式で表示するには `join(", ")` が使えます。
