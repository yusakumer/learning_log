# JavaScript 学習

JavaScriptの基本を、短い問題を自分で解きながら練習します。

## 進め方

1. `problem.md` を読む
2. 同じフォルダの `answer.js` に解答を書く
3. 問題フォルダで `node answer.js` を実行し、出力例と比べる
4. 解答後にレビューを受ける
