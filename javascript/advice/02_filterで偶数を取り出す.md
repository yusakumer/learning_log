# 02 filterで偶数を取り出す：レビューとメソッド解説

## レビュー

`numbers.filter((n) => n % 2 === 0)` で、偶数を元の順番のまま取り出せています。元の `numbers` も変更していません。

現在の出力は `[ 2, 8, 4 ]` です。問題の指定は `偶数: 2, 8, 4` なので、表示形式を合わせれば完成です。

変数名は `even_number` より、複数の値を表す `evenNumbers` のような名前がわかりやすいです。JavaScriptでは変数名にキャメルケースをよく使います。

## `filter` の引数と返り値

```javascript
const result = numbers.filter((number) => number % 2 === 0);
```

- `filter` に渡す引数は、各要素を残すか判定する関数です。この関数の第1引数 `number` には、配列の要素が1つずつ入ります。
- 判定する関数が `true` を返した要素だけが残ります。`false` を返した要素は除かれます。
- `filter` の返り値は、残った要素を集めた**新しい配列**です。元の配列は変更されません。
- 今回は `result` が `[2, 8, 4]` になります。

## `join` の引数と返り値

```javascript
const text = [2, 8, 4].join(", ");
// text は "2, 8, 4"
```

- `join` の引数は、要素の間に入れる区切り文字です。ここではカンマと半角スペースを指定しています。
- 返り値は、要素をつないだ**文字列**です。元の配列は変更されません。
- 引数を省略すると、区切り文字にはカンマが使われ、結果は `"2,8,4"` になります。

## `console.log` の引数と返り値

```javascript
console.log("偶数: " + text);
```

- 引数に渡した値をコンソールに表示します。複数の引数も渡せますが、今回は指定の1行を文字列として渡すと出力を合わせやすいです。
- 返り値は `undefined` です。表示した値が返るわけではありません。
