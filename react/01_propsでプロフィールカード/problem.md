# 01 props：プロフィールカード

## お題

名前と役割を表示する `ProfileCard` コンポーネントを作成してください。

- `name` と `role` をpropsとして受け取ります。
- 名前を見出し、役割をその下の文章として表示します。
- 2人分のカードを画面に表示します。
- 見出しには `h2`、役割には `p` を使います。

## 入力例

| 名前 | 役割 |
| --- | --- |
| Yusaku | フロントエンド学習中 |
| Hanako | デザイン担当 |

## 期待する表示

```text
Yusaku
フロントエンド学習中

Hanako
デザイン担当
```

## ヒント

- 同じコンポーネントを、渡すpropsを変えて2回使えます。
- JSXでは、propsの値を `{}` で囲んで表示できます。
- 今回はクリックなどの操作や状態管理は不要です。
