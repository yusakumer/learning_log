# React 学習

小さなコンポーネントを作りながら、Reactの基本を練習します。

## 進め方

1. `problem.md` を読む
2. 同じフォルダの `answer.jsx` に解答を書く
3. 練習用のReact環境でコンポーネントを表示して確認する
4. 解答後にレビューを受ける

このリポジトリには、まだReactの実行環境を設けていません。問題文と解答ファイルだけを置いています。
