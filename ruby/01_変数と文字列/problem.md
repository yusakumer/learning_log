# 変数と文字列

Ruby の変数への代入と、文字列の扱いを練習します。

## 問題1: 自己紹介を表示しよう

### お題

自分の名前を `name`、年齢を `age` という変数に代入してください。  
その後、次の形式で自己紹介を1行表示してください。

### 入力例

```text
name = "Taro"
age = 20
```

### 期待する出力例

```text
私の名前はTaroです。20歳です。
```

## 問題2: あいさつ文を作ろう

### お題

`first_name` に名前、`last_name` に名字を代入してください。  
2つの変数を使って、次の形式のあいさつ文を表示してください。

### 入力例

```text
first_name = "太郎"
last_name = "山田"
```

### 期待する出力例

```text
こんにちは、山田太郎さん！
```

## ヒント

- 文字列を画面に表示するには `puts` を使います。
- 文字列の中に変数の値を埋め込む書き方を調べてみましょう。
