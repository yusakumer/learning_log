# 条件分岐

`if` と `else` を使って、条件によって表示する内容を変える練習をします。

## 問題1: 年齢でメッセージを分けよう

### お題

`age` に年齢を代入してください。  
年齢が18以上なら `成人です。`、18未満なら `未成年です。` と表示してください。

### 入力例1

```text
age = 20
```

### 期待する出力例1

```text
成人です。
```

### 入力例2

```text
age = 16
```

### 期待する出力例2

```text
未成年です。
```

## 問題2: 点数で合否を判定しよう

### お題

`score` にテストの点数を代入してください。  
点数が60点以上なら `合格です！`、60点未満なら `もう一度がんばりましょう。` と表示してください。

### 入力例1

```text
score = 75
```

### 期待する出力例1

```text
合格です！
```

### 入力例2

```text
score = 45
```

### 期待する出力例2

```text
もう一度がんばりましょう。
```

## ヒント

- 条件分岐は `if 条件` で始め、最後に `end` を書きます。
- 「〜以上」は `>=`、「〜未満」は `<` で表せます。
- `if` の条件が成り立たないときの処理には `else` を使います。
