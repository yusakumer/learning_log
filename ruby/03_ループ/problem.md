# ループ

繰り返し処理と条件分岐を組み合わせて、複数の数値を扱う練習をします。

## 問題1: 奇数だけを表示しよう

### お題

1から10までの数値を順番に調べてください。  
その中で奇数だけを、1行ずつ表示してください。

### 入力例

```text
1から10までの数値
```

### 期待する出力例

```text
1
3
5
7
9
```

## 問題2: 偶数だけを合計しよう

### お題

1から20までの数値を順番に調べてください。  
偶数だけを合計し、最後に次の形式で表示してください。

### 入力例

```text
1から20までの数値
```

### 期待する出力例

```text
偶数の合計は110です。
```

## ヒント

- `(1..10).each do |number|` の形で、範囲内の数値を順番に扱えます。
- `number % 2 == 1` は奇数、`number % 2 == 0` は偶数かどうかを調べる条件です。
- 合計用の変数は、ループの前に `0` で用意します。
- 変数の値に足して更新するには `+=` を使えます。
