# 配列

複数の値を配列にまとめ、`each` を使って処理する練習をします。

## 問題1: 合格した点数だけを表示しよう

### お題

次のテストの点数を配列 `scores` に代入してください。

```text
72, 45, 88, 59, 91
```

`scores` の各点数を順番に調べ、60点以上の点数だけを1行ずつ表示してください。

### 入力例

```text
scores = [72, 45, 88, 59, 91]
```

### 期待する出力例

```text
72
88
91
```

## 問題2: 平均点を計算しよう

### お題

問題1と同じ `scores` を使って、全ての点数の合計と平均点を計算してください。  
最後に、次の形式で表示してください。

平均点は小数ではなく、整数で表示してください。

### 入力例

```text
scores = [72, 45, 88, 59, 91]
```

### 期待する出力例

```text
合計点は355点です。
平均点は71点です。
```

## ヒント

- 配列は `[値1, 値2, 値3]` のように書きます。
- `scores.each do |score|` と書くと、各点数を順番に取り出せます。
- 要素数は `scores.length` で取得できます。
- 整数同士を `/` で割ると、結果は整数になります。
