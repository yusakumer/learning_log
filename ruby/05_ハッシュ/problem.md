# ハッシュ

ハッシュを使って、名前や在庫数のように「項目名」と「値」をセットで扱う練習をします。

## 問題1: プロフィールを表示しよう

### お題

次の情報をハッシュ `profile` に格納してください。

| 項目 | 値 |
| --- | --- |
| 名前 | Yusaku |
| 年齢 | 27 |
| 居住地 | Tokyo |

`profile` から値を取り出し、次の形式で表示してください。

### 入力例

```text
profile = {
  name: "Yusaku",
  age: 27,
  city: "Tokyo"
}
```

### 期待する出力例

```text
YusakuさんはTokyoに住んでいます。27歳です。
```

## 問題2: 在庫を確認しよう

### お題

次の商品名と在庫数をハッシュ `stocks` に格納してください。

| 商品名 | 在庫数 |
| --- | --- |
| apple | 3 |
| banana | 0 |
| orange | 5 |
| grape | 0 |

`stocks` の各商品を順番に調べてください。  
在庫が1個以上なら `商品名: 在庫あり（在庫数個）`、0個なら `商品名: 在庫切れ` と1行ずつ表示してください。

### 入力例

```text
stocks = {
  apple: 3,
  banana: 0,
  orange: 5,
  grape: 0
}
```

### 期待する出力例

```text
apple: 在庫あり（3個）
banana: 在庫切れ
orange: 在庫あり（5個）
grape: 在庫切れ
```

## ヒント

- ハッシュでは、項目を表す名前と値をセットで管理します。
- プロフィールでは、必要な項目を指定して値を取り出します。
- 在庫確認では、各商品の「商品名」と「在庫数」を順番に扱います。
- 在庫数に応じて、表示内容を分岐させます。
