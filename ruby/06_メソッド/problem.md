# メソッド

同じような処理に名前を付け、必要な値を渡して使う練習をします。

## 問題1: あいさつメソッドを作ろう

### お題

名前を1つ受け取り、その人へのあいさつを表示する `greet` メソッドを作成してください。

次のようにメソッドを呼び出したとき、期待する出力になるようにします。

### 入力例

```text
greet("Yusaku")
greet("Taro")
```

### 期待する出力例

```text
こんにちは、Yusakuさん！
こんにちは、Taroさん！
```

## 問題2: 合否を返すメソッドを作ろう

### お題

点数を1つ受け取り、60点以上なら `合格`、60点未満なら `不合格` という文字列を返す `judge_score` メソッドを作成してください。

メソッドの戻り値を使って、次の形式で結果を表示してください。

### 入力例

```text
score1 = 75
score2 = 48
```

### 期待する出力例

```text
75点: 合格
48点: 不合格
```

## ヒント

- メソッドは「処理に名前を付けて、必要なときに呼び出せる」仕組みです。
- 問題1では名前、問題2では点数を、メソッドの外から受け取る必要があります。
- 問題2は、画面への表示ではなく、判定結果の文字列を呼び出し元へ渡すことを意識してください。
