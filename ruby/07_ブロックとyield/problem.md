# ブロックと yield

メソッドを呼び出す側から処理を渡し、メソッドの中で実行する仕組みを練習します。

## 問題1: 同じ処理を3回実行しよう

### お題

呼び出し側で渡された処理を、3回実行する `three_times` メソッドを作成してください。

メソッドを呼び出すときに「Rubyを学習中です」と表示する処理を渡し、次の出力になるようにします。

### 入力例

```text
three_times に「Rubyを学習中です」と表示する処理を渡す
```

### 期待する出力例

```text
Rubyを学習中です
Rubyを学習中です
Rubyを学習中です
```

## 問題2: 回数を指定してメッセージを表示しよう

### お題

実行回数を受け取り、渡された処理をその回数だけ実行する `repeat` メソッドを作成してください。

渡された処理には、何回目の実行かを1から始まる数値で渡します。  
`repeat` を5回指定で呼び出し、次の出力になるようにしてください。

### 入力例

```text
repeat に 5 を渡し、「何回目か」と「Ruby」を表示する処理を渡す
```

### 期待する出力例

```text
1回目: Ruby
2回目: Ruby
3回目: Ruby
4回目: Ruby
5回目: Ruby
```

## ヒント

- ブロックは、メソッド呼び出しの際に追加で渡せる処理のかたまりです。
- メソッド側では、受け取った処理を好きな回数だけ実行できます。
- 問題2では「今何回目か」という数値も、呼び出し側の処理で使えるようにします。
