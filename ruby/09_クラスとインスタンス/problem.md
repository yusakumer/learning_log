# クラスとインスタンス

関連するデータと処理をひとつにまとめる、クラスの基本を練習します。

## 問題1: 自己紹介する Person を作ろう

### お題

名前と年齢を持つ `Person` クラスを作成してください。

作成時に名前と年齢を受け取り、自己紹介文を返す `introduction` メソッドを持たせます。  
`Person` を1人分作成し、自己紹介文を表示してください。

### 入力例

```text
名前: Yusaku
年齢: 27
```

### 期待する出力例

```text
私はYusakuです。27歳です。
```

## 問題2: 数を数える Counter を作ろう

### お題

現在の数を管理する `Counter` クラスを作成してください。

- 作成直後の数は `0`
- 数を1増やす `increment` メソッドを持つ
- 現在の数を返す `value` メソッドを持つ

`Counter` を1つ作成して `increment` を3回呼び出し、最後に現在の数を次の形式で表示してください。

### 入力例

```text
Counterを作成する
incrementを3回呼び出す
```

### 期待する出力例

```text
カウント: 3
```

## ヒント

- クラスは、関連するデータと処理をまとめるための設計図です。
- 作成時に受け取った値や、途中で変化する値は、それぞれのオブジェクトが覚えておく必要があります。
- 問題1では自己紹介文を返すこと、問題2では数を増やした後の状態を保持することを意識してください。
