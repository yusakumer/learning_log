# attr_accessor

インスタンス変数を外から安全に読み書きするための、`attr_accessor` を練習します。

## 問題1: プロフィールを更新しよう

### お題

名前と年齢を持つ `Profile` クラスを作成してください。

- `attr_accessor` を使って、名前と年齢を読み書きできるようにする
- 作成時に名前と年齢を受け取る
- 自己紹介文を返す `introduction` メソッドを持たせる
- インスタンスを作成した後で年齢を更新し、自己紹介文を表示する

### 入力例

```text
名前: Yusaku
年齢: 27
更新後の年齢: 28
```

### 期待する出力例

```text
私はYusakuです。28歳です。
```

## 問題2: 本の情報を管理しよう

### お題

タイトルと貸出状況を持つ `Book` クラスを作成してください。

- `attr_reader` を使ってタイトルを読み取れるようにする
- 本を作成した直後の貸出状況は「貸出可能」にする
- 本を借りる `borrow` メソッドを作り、貸出状況を「貸出中」に変更する
- 現在の貸出状況を返す `status` メソッドを作る

`Book` を1冊作成して借りる処理を行い、タイトルと貸出状況を表示してください。

### 入力例

```text
タイトル: Ruby入門
本を借りる
```

### 期待する出力例

```text
Ruby入門は貸出中です。
```

## ヒント

- `attr_accessor :name` と書くと、`@name` を読み書きするメソッドをまとめて定義できます。
- `attr_reader` は読み取りだけを許可したいときに使います。
- 貸出状況のように、クラスの内部でだけ変更したい値はインスタンス変数として管理してみましょう。
