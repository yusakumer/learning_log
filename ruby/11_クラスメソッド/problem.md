# クラスメソッド

インスタンスを作らずにクラスから呼び出せる、クラスメソッドを練習します。

## 問題1: 温度を変換しよう

### お題

摂氏を華氏へ変換する `Temperature` クラスを作成してください。

- クラスメソッド `celsius_to_fahrenheit` を定義する
- このメソッドは摂氏の数値を受け取り、華氏へ変換した値を返す
- 変換式は `華氏 = 摂氏 × 9 / 5 + 32` とする

`Temperature` のインスタンスは作らずに、クラスメソッドを使って摂氏25度を華氏へ変換し、結果を表示してください。

### 入力例

```text
摂氏: 25
```

### 期待する出力例

```text
摂氏25度は華氏77度です。
```

## 問題2: ユーザー数を数えよう

### お題

作成されたユーザーの人数を管理する `User` クラスを作成してください。

- 作成時に名前を受け取る
- インスタンスが1つ作られるたびに、ユーザー数を1増やす
- 現在のユーザー数を返すクラスメソッド `count` を作る
- ユーザーを2人作成した後で、ユーザー数を表示する

### 入力例

```text
名前: Yusaku
名前: Hanako
```

### 期待する出力例

```text
登録ユーザー数: 2人
```

## ヒント

- クラスメソッドは `def self.メソッド名` の形式で定義できます。
- クラスメソッドは `クラス名.メソッド名` の形式で呼び出します。
- すべてのインスタンスで共有したい値は、クラス変数またはクラスインスタンス変数として考えてみましょう。
