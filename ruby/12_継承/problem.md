# 継承

既存のクラスの機能を引き継いで新しいクラスを作る、継承を練習します。

## 問題1: 動物を鳴かせよう

### お題

動物を表す `Animal` クラスと、それを継承する `Dog` クラスを作成してください。

- `Animal` クラスは、名前を受け取って覚える
- `Animal` クラスに、名前を使った自己紹介を返す `introduce` メソッドを作る
- `Dog` クラスは `Animal` クラスを継承する
- `Dog` クラスに、犬の鳴き声を返す `speak` メソッドを作る

`Dog` のインスタンスを作成し、自己紹介と鳴き声を表示してください。

### 入力例

```text
名前: ポチ
```

### 期待する出力例

```text
私はポチです。
ワンワン！
```

## 問題2: 社員とマネージャーを作ろう

### お題

社員を表す `Employee` クラスと、それを継承する `Manager` クラスを作成してください。

- `Employee` クラスは名前を受け取る
- `Employee` クラスに、名前を使ってあいさつする `greet` メソッドを作る
- `Manager` クラスは `Employee` クラスを継承する
- `Manager` クラスに、チームを管理することを伝える `manage_team` メソッドを作る

`Manager` のインスタンスを作成し、あいさつとチーム管理のメッセージを表示してください。

### 入力例

```text
名前: Yusaku
```

### 期待する出力例

```text
私はYusakuです。よろしくお願いします。
チームを管理します。
```

## ヒント

- 継承は `class 子クラス < 親クラス` の形式で定義します。
- 子クラスは親クラスのインスタンスメソッドをそのまま使えます。
- 子クラス固有の処理は、子クラスの中に新しくメソッドとして定義します。
