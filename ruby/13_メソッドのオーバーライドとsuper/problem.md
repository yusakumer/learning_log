# メソッドのオーバーライドと `super`

親クラスから受け継いだメソッドを子クラスで作り直す「オーバーライド」と、親クラスの処理を呼び出す `super` を練習します。

## 問題1: 犬らしい自己紹介を作ろう

### お題

名前を持つ `Animal` クラスと、それを継承する `Dog` クラスを作成してください。

- `Animal` クラスに、`introduce` メソッドを作る
- `introduce` メソッドは「私は名前です。」という文字列を返す
- `Dog` クラスで `introduce` メソッドをオーバーライドする
- `Dog` クラスの `introduce` メソッドは「私は名前です。犬です。」という文字列を返す

`Dog` のインスタンスを作成して、自己紹介を表示してください。

### 入力例

```text
名前: ポチ
```

### 期待する出力例

```text
私はポチです。犬です。
```

## 問題2: 親クラスの初期化を利用しよう

### お題

名前と年齢を持つ `Person` クラスと、それを継承する `Student` クラスを作成してください。

- `Person` クラスの `initialize` で名前と年齢を受け取る
- `Student` クラスでは、名前・年齢・学校名を受け取る
- `Student` クラスの `initialize` から `super` を使い、親クラスの名前と年齢の初期化を行う
- `Student` クラスに、名前・年齢・学校名を使った `introduction` メソッドを作る

`Student` のインスタンスを作成し、自己紹介を表示してください。

### 入力例

```text
名前: Yusaku
年齢: 27
学校名: Ruby学校
```

### 期待する出力例

```text
私はYusakuです。27歳で、Ruby学校に通っています。
```

## ヒント

- 子クラスで親クラスと同じ名前のメソッドを定義すると、子クラス側のメソッドが使われます。
- `super` は親クラスの同名メソッドを呼び出します。
- `super(name, age)` のように、親クラスの `initialize` に値を渡せます。
