# モジュールと `include`

複数のクラスで共通して使える機能をまとめる、モジュールを練習します。

## 問題1: あいさつ機能を追加しよう

### お題

あいさつを返す `Greeting` モジュールを作成してください。

- `Greeting` モジュールに、`greet` メソッドを作る
- `greet` メソッドは「こんにちは！」を返す
- `Person` クラスで `Greeting` モジュールを `include` する
- `Person` のインスタンスから `greet` を呼び出して表示する

### 入力例

```text
Personのインスタンスを作成する
```

### 期待する出力例

```text
こんにちは！
```

## 問題2: 2つのクラスで共通機能を使おう

### お題

ログを表示する `Loggable` モジュールを作成してください。

- `Loggable` モジュールに、受け取ったメッセージの先頭へ `[LOG] ` を付けて返す `log` メソッドを作る
- `User` クラスと `Admin` クラスで `Loggable` モジュールを `include` する
- それぞれのインスタンスから `log` を呼び出し、結果を表示する

### 入力例

```text
User: ログインしました
Admin: 設定を変更しました
```

### 期待する出力例

```text
[LOG] ログインしました
[LOG] 設定を変更しました
```

## ヒント

- モジュールは `module モジュール名` で定義します。
- `include モジュール名` と書くと、モジュールのインスタンスメソッドをクラスで使えます。
- 同じ機能を複数のクラスで使いたいときにモジュールが役立ちます。
