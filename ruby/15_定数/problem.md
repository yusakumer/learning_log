# 定数

プログラム内で変わらない値に名前を付ける、定数を練習します。

## 問題1: 消費税を計算しよう

### お題

消費税を計算する `PriceCalculator` クラスを作成してください。

- 消費税率 `0.1` を `TAX_RATE` という定数で定義する
- 税抜き価格を受け取り、税込み価格を返す `with_tax` メソッドを作る
- 税抜き価格1000円の税込み価格を表示する

### 入力例

```text
税抜き価格: 1000円
```

### 期待する出力例

```text
税込み価格: 1100円
```

## 問題2: ゲームの設定値を使おう

### お題

ゲームの設定を持つ `Game` クラスを作成してください。

- 最大プレイヤー数 `4` を `MAX_PLAYERS` という定数で定義する
- 最大プレイヤー数を返す `max_players` メソッドを作る
- `Game` のインスタンスを作成し、最大プレイヤー数を表示する

### 入力例

```text
Gameのインスタンスを作成する
```

### 期待する出力例

```text
最大プレイヤー数: 4人
```

## ヒント

- 定数名は、慣例としてすべて大文字で書きます。
- クラスの中で定義した定数は、そのクラスのメソッドから名前だけで参照できます。
- 定数は変更しない値に使うと、数字の意味がわかりやすくなります。
