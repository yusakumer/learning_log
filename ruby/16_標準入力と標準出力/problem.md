# 標準入力と標準出力

Paizaのようなプログラミング問題を解くために必要な、標準入力（`gets`）と標準出力（`puts`）を練習します。

## 問題1: 名前を受け取ってあいさつしよう

### お題

標準入力から名前を1行受け取り、次の形式で表示してください。

### 入力例

```text
Yusaku
```

### 期待する出力例

```text
こんにちは、Yusakuさん！
```

## 問題2: 2つの整数を足そう

### お題

標準入力から、半角スペースで区切られた2つの整数を受け取り、その合計を表示してください。

### 入力例

```text
12 30
```

### 期待する出力例

```text
42
```

## 実行例

ターミナルで次のように実行すると、キーボードから値を入力できます。

```bash
ruby answer.rb
```

または、入力例を使ってまとめて確認できます。

```bash
printf 'Yusaku\n' | ruby answer.rb
```

問題1と問題2は、別々に実行して確認してください。

## ヒント

- `gets` は1行の入力を受け取ります。
- `gets.chomp` とすると、入力末尾の改行を取り除けます。
- `gets.split` は、半角スペースで区切られた入力を配列に分けます。
- 文字列を整数に変換するには `to_i` を使います。
