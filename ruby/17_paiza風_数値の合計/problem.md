# Paiza風問題 1: 数値の合計

## 問題

1行目に整数 `N` が与えられます。  
続く `N` 行には、それぞれ整数が1つずつ与えられます。

与えられた `N` 個の整数の合計を出力してください。

## 入力形式

```text
N
a_1
a_2
...
a_N
```

- `N` は整数の個数です
- `a_1` から `a_N` は合計したい整数です

## 制約

- `1 <= N <= 100`
- `0 <= a_i <= 10,000`

## 入力例

```text
3
10
20
30
```

## 期待する出力例

```text
60
```

## 実行方法

解答を書いた後、次のコマンドで入力例を使って確認できます。

```bash
printf '3\n10\n20\n30\n' | ruby answer.rb
```

## ヒント

- 1行目は `gets.to_i` で整数として受け取れます。
- `N` 回同じ処理を繰り返すには `times` が使えます。
- 合計用の変数を最初に `0` で用意し、入力された値を順に足してみましょう。
