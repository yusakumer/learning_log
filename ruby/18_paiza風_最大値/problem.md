# Paiza風問題 2: 最大値を見つける

## 問題

1行目に整数 `N` が与えられます。  
続く `N` 行には、それぞれ整数が1つずつ与えられます。

与えられた `N` 個の整数のうち、もっとも大きい値を出力してください。

## 入力形式

```text
N
a_1
a_2
...
a_N
```

## 制約

- `1 <= N <= 100`
- `0 <= a_i <= 10,000`

## 入力例

```text
5
8
3
15
6
10
```

## 期待する出力例

```text
15
```

## 実行方法

```bash
printf '5\n8\n3\n15\n6\n10\n' | ruby answer.rb
```

## ヒント

- 最大値を入れる変数を、最初は `0` で用意してみましょう。
- 入力した数が現在の最大値より大きいときだけ、最大値を更新します。
- `if` 文と `times` を組み合わせてみましょう。
