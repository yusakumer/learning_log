# Paiza風問題 3: 条件に合う数を数える

## 問題

1行目に整数 `N` と整数 `X` が半角スペース区切りで与えられます。  
2行目に `N` 個の整数が半角スペース区切りで与えられます。

`X` 以上の整数が何個あるかを出力してください。

## 入力形式

```text
N X
a_1 a_2 ... a_N
```

## 制約

- `1 <= N <= 100`
- `0 <= X <= 10,000`
- `0 <= a_i <= 10,000`

## 入力例

```text
5 10
8 10 15 6 12
```

## 期待する出力例

```text
3
```

## 実行方法

```bash
printf '5 10\n8 10 15 6 12\n' | ruby answer.rb
```

## ヒント

- 1行目は `gets.split` で2つの値に分けられます。
- 文字列を整数に変換するには `to_i` を使います。
- 2行目の数値を配列にした後、1つずつ `X` 以上か調べてみましょう。
- 条件を満たした回数を数える変数を、最初に `0` で用意すると考えやすくなります。
