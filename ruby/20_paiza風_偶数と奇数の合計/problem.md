# Paiza風問題 4: 偶数と奇数の合計

## 問題

1行目に整数 `N` が与えられます。  
続く `N` 行には、それぞれ整数が1つずつ与えられます。

与えられた整数のうち、偶数の合計を1行目に、奇数の合計を2行目に出力してください。

## 入力形式

```text
N
a_1
a_2
...
a_N
```

## 制約

- `1 <= N <= 100`
- `0 <= a_i <= 10,000`

## 入力例

```text
5
1
2
3
4
5
```

## 期待する出力例

```text
6
9
```

## 実行方法

```bash
printf '5\n1\n2\n3\n4\n5\n' | ruby answer.rb
```

## ヒント

- 偶数かどうかは `number.even?` で調べられます。
- 偶数用と奇数用に、合計を保存する変数をそれぞれ `0` で用意しましょう。
- `if` と `else` で、足し算をする先を分けてみましょう。
