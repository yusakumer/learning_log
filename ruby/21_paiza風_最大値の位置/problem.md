# Paiza風問題 5: 最大値の位置

## 問題

1行目に整数 `N` が与えられます。  
続く `N` 行には、それぞれ整数が1つずつ与えられます。

与えられた `N` 個の整数のうち、もっとも大きい値が入力された位置を出力してください。  
位置は、最初の数を1番目として数えます。最大値は必ず1つだけ存在します。

## 入力形式

```text
N
a_1
a_2
...
a_N
```

## 制約

- `1 <= N <= 100`
- `0 <= a_i <= 10,000`
- 最大値は1つだけ存在する

## 入力例

```text
5
8
3
15
6
10
```

## 期待する出力例

```text
3
```

## 実行方法

```bash
printf '5\n8\n3\n15\n6\n10\n' | ruby answer.rb
```

## ヒント

- 最大値だけでなく、その位置を保存する変数も用意します。
- `times do |index|` の `index` は0から始まるので、出力するときは `index + 1` を使います。
- 今までの最大値より大きい値を見つけたとき、最大値と位置を両方更新します。
