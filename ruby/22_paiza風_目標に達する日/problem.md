# Paiza風問題 6: 目標に達する日

## 問題

1行目に日数 `N` と目標値 `X` が半角スペース区切りで与えられます。  
続く `N` 行には、各日に増える値が1つずつ与えられます。

1日目から順に値を足していったとき、合計が初めて `X` 以上になるのは何日目かを出力してください。  
`N` 日目までには必ず `X` 以上になります。

## 入力形式

```text
N X
a_1
a_2
...
a_N
```

## 制約

- `1 <= N <= 100`
- `1 <= X <= 100,000`
- `1 <= a_i <= 10,000`
- `a_1 + a_2 + ... + a_N >= X`

## 入力例

```text
5 20
5
8
4
10
3
```

## 期待する出力例

```text
4
```

## 説明

1日目からの合計は順に `5`、`13`、`17`、`27` です。  
4日目に初めて20以上になるため、`4` を出力します。

## 実行方法

```bash
printf '5 20\n5\n8\n4\n10\n3\n' | ruby answer.rb
```

## ヒント

- 合計を保存する変数を `0` で用意します。
- 各日の値を読み取るたびに、合計へ足します。
- 合計が `X` 以上になったら、そのときの位置を出力して `break` で繰り返しを終えます。
