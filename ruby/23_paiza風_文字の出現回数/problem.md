# Paiza風問題 7: 文字の出現回数

## 問題

1行目に英小文字だけからなる文字列 `S` が与えられます。  
2行目に英小文字1文字 `C` が与えられます。

文字列 `S` の中に、文字 `C` が何回出現するかを出力してください。

## 入力形式

```text
S
C
```

## 制約

- `S` は1文字以上100文字以下の英小文字からなる
- `C` は英小文字1文字である

## 入力例

```text
banana
a
```

## 期待する出力例

```text
3
```

## 実行方法

```bash
printf 'banana\na\n' | ruby answer.rb
```

## ヒント

- 文字列は `gets.chomp` で受け取れます。
- `each_char` を使うと、文字列を1文字ずつ繰り返し処理できます。
- 1文字が `C` と同じなら、カウンターを1増やしてみましょう。
