# Paiza風問題 8: 回文判定

## 問題

1行目に英小文字だけからなる文字列 `S` が与えられます。

`S` を前から読んでも後ろから読んでも同じ場合は `YES`、異なる場合は `NO` と出力してください。

## 入力形式

```text
S
```

## 制約

- `S` は1文字以上100文字以下の英小文字からなる

## 入力例1

```text
level
```

## 期待する出力例1

```text
YES
```

## 入力例2

```text
ruby
```

## 期待する出力例2

```text
NO
```

## 実行方法

```bash
printf 'level\n' | ruby answer.rb
printf 'ruby\n' | ruby answer.rb
```

## ヒント

- 入力は `gets.chomp` で受け取れます。
- `reverse` を使うと文字列を逆順にできます。
- 元の文字列と逆順の文字列を `==` で比較してみましょう。
