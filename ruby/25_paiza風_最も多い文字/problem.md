# Paiza風問題 9: 最も多い文字

## 問題

1行目に英小文字だけからなる文字列 `S` が与えられます。

`S` に最も多く現れる文字を1文字だけ出力してください。最も多く現れる文字は必ず1種類だけです。

## 入力形式

```text
S
```

## 制約

- `S` は1文字以上100文字以下の英小文字からなる
- 出現回数が最大の文字は1種類だけである

## 入力例1

```text
banana
```

## 期待する出力例1

```text
a
```

## 入力例2

```text
mississippii
```

## 期待する出力例2

```text
i
```

## 実行方法

```bash
printf 'banana\n' | ruby answer.rb
printf 'mississippii\n' | ruby answer.rb
```

## ヒント

- `gets.chomp` で文字列を受け取れます。
- `each_char` で1文字ずつ取り出せます。
- ハッシュを使い、文字ごとに何回現れたかを記録してみましょう。
- 最後に、最も大きい回数を持つ文字を探します。
