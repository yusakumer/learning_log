# Paiza風問題 10: 同じ文字の最長連続

## 問題

1行目に英小文字だけからなる文字列 `S` が与えられます。

同じ文字が連続している長さの最大値を出力してください。

## 入力形式

```text
S
```

## 制約

- `S` は1文字以上100文字以下の英小文字からなる

## 入力例1

```text
aaabbccccd
```

## 期待する出力例1

```text
4
```

`c` が4文字連続しているためです。

## 入力例2

```text
abc
```

## 期待する出力例2

```text
1
```

## 実行方法

```bash
printf 'aaabbccccd\n' | ruby answer.rb
printf 'abc\n' | ruby answer.rb
```

## ヒント

- `each_char` で文字を順番に見ていきます。
- 直前の文字、現在の連続回数、これまでの最大回数をそれぞれ覚えておきます。
- 今の文字が直前の文字と同じなら連続回数を増やし、違えば連続回数を `1` に戻します。
