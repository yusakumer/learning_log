# Paiza風問題 11: 連続文字の圧縮

## 問題

英小文字だけからなる文字列 `S` が1行で与えられます。

同じ文字が連続している部分を、文字とその連続回数に置き換えて出力してください。連続回数が `1` の部分も、必ず `1` を付けてください。

## 入力形式

```text
S
```

## 制約

- `S` は1文字以上100文字以下の英小文字からなる

## 入力例1

```text
aaabbccccd
```

## 期待する出力例1

```text
a3b2c4d1
```

## 入力例2

```text
ababa
```

## 期待する出力例2

```text
a1b1a1b1a1
```

## 実行方法

```bash
printf 'aaabbccccd\n' | ruby answer.rb
printf 'ababa\n' | ruby answer.rb
```

## ヒント

- 問題26と同じように、直前の文字と現在の連続回数を覚えておきます。
- 文字が変わった時点で、それまでの文字と回数を結果へ追加します。
- 最後のグループでは次の文字が来ないため、繰り返しが終わった後にも結果へ追加する必要があります。
