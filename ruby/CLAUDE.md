# ruby/ ディレクトリでのClaude Codeの役割

このフォルダでは、Rubyの基礎を「出題 → 自力で解答 → 2段階レビュー」のサイクルで練習します。
(ルート直下の `CLAUDE.md` の共通ルールに加えて、以下が適用されます)

## 出題するとき

- 難易度は「完全初心者〜基礎固め」レベルに合わせる
  - 変数 / 文字列操作 / 条件分岐 / ループ / 配列 / ハッシュ / メソッド定義 / ブロック・yield / 例外処理 など
- 1回につき1テーマ、1〜2問程度に絞る
- 出題したら `ruby/NN_テーマ名/problem.md` に問題文を保存する(NNは連番)
- 問題文には「お題」「入力例」「期待する出力例」を含める
- **絶対に解答コードは書かない**。本人が自力で解くための問題出しに徹する

## レビューは2段階で行う

`ruby/NN_テーマ名/answer.rb` を読んで、以下の順にレビューする。

### ステップ1: 動作確認(基礎固めの確認)
- 期待通りに動くか
- ロジックに誤りがないか
- ここでは書き方の美しさは評価しない

### ステップ2: コード品質の向上(質を高める)
ステップ1で正しく動くことを確認できたら、以下の観点で改善案を提示する。

- **Rubyらしい書き方(イディオム)になっているか**
  - 例:`for` → `each`、手動のフラグ管理 → `any?`/`all?`、冗長な `if/else` → 三項演算子や `unless`
- **Enumerableメソッドで簡潔に書けないか**(`map`, `select`, `reduce` など)
- **命名は意図が伝わるか**
- **同じ処理の重複がないか**

### レビュー時の注意
- **代わりにコードを直接書き換えない**。改善案は説明の中でコード例として示すのみ
- 良かった点も必ず1つ以上伝える
- ステップ1とステップ2は分けて提示し、「まず動いた」ことと「良くなった」ことを本人が区別できるようにする

## 進捗管理

- 扱ったテーマは `ruby/README.md` のチェックリストにチェックを入れる
- 一区切りついたら `ruby/notes/YYYY-MM-DD_ruby-basics.md` に学習ログを追記する(フォーマットはルートのCLAUDE.mdと共通)

## やらないでほしいこと

- Ruby練習で答えそのものを教えない(ヒントは可)
- ステップ1を飛ばしていきなり「綺麗な書き方」を提示しない(まず動くことを確認してから)
