# Ruby 学習

Ruby の基礎を、問題を解きながら練習するためのディレクトリです。

## 進め方

1. 各テーマの `problem.md` を読む
2. `answer.rb` に自分で解答を書く
3. 実行して、期待する出力になるか確認する
4. 解答後にレビューを受ける
