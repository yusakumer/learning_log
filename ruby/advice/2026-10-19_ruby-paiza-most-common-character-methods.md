# Paiza風問題 9：使用メソッドとRubyらしい書き方

[問題25の解答](../25_paiza風_最も多い文字/answer.rb)で使ったメソッドを、入力・集計・結果の取得に分けて説明します。

## `gets` と `chomp`：入力を受け取る

- **`gets` の引数:** 今回はありません。標準入力を1行読みます。
- **`gets` の戻り値:** 読み取った文字列。通常は行末の改行を含み、入力がなければ `nil` です。
- **`chomp` の引数:** 今回はありません。引数を指定すれば取り除く行末の区切り文字列を変えられます。
- **`chomp` の戻り値:** 行末の改行を除いた新しい文字列。元の文字列は変更しません。

たとえば `banana` を入力すると、`gets` は `"banana\n"`、`gets.chomp` は `"banana"` を返します。

## `Hash.new`：空のハッシュを作る

- **呼び出し方:** `Hash.new`
- **引数:** この解答ではありません。`Hash.new(0)` と書くと、存在しないキーを読んだときの既定値を `0` にできます。
- **戻り値:** 新しいハッシュ。
- **この問題での役割:** 文字ごとの出現回数を入れる場所を用意します。

`Hash.new` で作ったハッシュは、まだ登録していないキーを `hash[char]` で読むと `nil` を返します。そのため、現在の解答では初回だけ `1` を代入しています。

## `each_char`：文字を1つずつ処理する

- **呼び出し方:** `string.each_char do |char| ... end`
- **引数:** 通常の引数はありません。ブロックに各文字が1つずつ渡されます。
- **戻り値:** ブロックを付けた場合は元の文字列。ブロックなしでは繰り返しに使える `Enumerator` を返します。
- **この問題での役割:** `banana` なら `b`、`a`、`n`、`a`、`n`、`a` を順に取り出します。

## `hash[char]` と `hash[char] = value`：回数を読む・書く

- **`[]` の引数:** 調べたいキー。今回は1文字の `char` です。
- **`[]` の戻り値:** その文字に保存した回数。未登録なら、`Hash.new` の場合は `nil`、`Hash.new(0)` の場合は `0` です。
- **`[]=` の引数:** キーと保存する値。`hash[char] = 1` は文字の回数を `1` にします。
- **`[]=` の結果:** 代入した値を式の値として使えます。この問題では保存する効果を使っています。

`hash[char] += 1` は、保存済みの数値を読み、`1` 足して、同じキーに書き戻します。

## `max_by`：回数が最大の組を選ぶ

- **呼び出し方:** `hash.max_by { |char, count| count }`
- **引数:** 通常の引数はありません。ブロックは、各組から比較に使う値を返します。ここでは出現回数 `count` を返します。
- **戻り値:** 最大と判定されたキーと値の組を配列で返します。たとえば `["a", 3]` です。空のハッシュなら `nil` です。
- **この問題での役割:** 最も多い文字とその回数を一緒に取り出します。

解答の `|k, v|` は、ハッシュのキーと値を受け取るブロック引数です。`max_by` の結果に `[0]` を付けると、組の先頭にある文字だけを取り出せます。今回は文字列が1文字以上なので、ハッシュは空になりません。

## `puts`：答えを出力する

- **引数:** 出力したい値。今回は最も多く現れた文字です。
- **戻り値:** `nil`。文字と改行を標準出力へ書き込みます。

## Rubyらしい書き方のアドバイス

今の解答は、初めて出た文字と2回目以降を正しく分けられています。`Hash.new(0)` を使うと、集計部分を次のように書けます。

```ruby
text = gets.chomp
counts = Hash.new(0)

text.each_char do |char|
  counts[char] += 1
end

most_common_char, = counts.max_by { |char, count| count }
puts most_common_char
```

`Hash.new(0)` は未登録のキーを読んだときに `0` を返すため、最初の文字も `0 + 1` で数えられます。`hash` より `counts` のほうが中身を表し、`k, v` より `char, count` のほうが比較している値を読み取りやすくなります。
