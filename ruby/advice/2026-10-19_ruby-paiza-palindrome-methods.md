# Paiza風問題 8：使用メソッドとRubyらしい書き方

[問題24の解答](../24_paiza風_回文判定/answer.rb)で使ったメソッドと比較を整理します。

## `gets`：入力を1行読む

- **呼び出し方:** `gets`
- **引数:** 今回は渡しません。
- **戻り値:** 入力した1行を表す文字列。通常は末尾の改行も含みます。入力がなければ `nil` を返します。
- **この問題での役割:** 判定する文字列を受け取ります。

たとえば `level` を入力して Enter を押すと、`"level\n"` を受け取ります。

## `to_s`：文字列に変換する

- **呼び出し方:** `値.to_s`
- **引数:** ありません。
- **戻り値:** 値を文字列にしたもの。文字列に対して呼べばその文字列、`nil` に対して呼べば空文字列 `""` です。
- **この解答での役割:** `gets` の戻り値を文字列にしてから `chomp` を呼びます。

この問題では入力が必ず1行あるため、`gets` は文字列を返します。`to_s` を省いて `gets.chomp` と書けます。

## `chomp`：末尾の改行を取り除く

- **呼び出し方:** `文字列.chomp`
- **引数:** 今回は渡しません。引数で取り除く行末の区切り文字列を指定することもできます。
- **戻り値:** 末尾の改行を取り除いた新しい文字列。元の文字列は変更しません。
- **この問題での役割:** `"level\n"` を `"level"` にします。

## `reverse`：文字列を逆順にする

- **呼び出し方:** `文字列.reverse`
- **引数:** ありません。
- **戻り値:** 文字の並びを逆にした新しい文字列。元の文字列は変更しません。
- **例:** `"level".reverse` は `"level"`、`"ruby".reverse` は `"ybur"` を返します。
- **この問題での役割:** 元の文字列と比較するための逆順の文字列を作ります。

## `==`：2つの値が等しいか調べる

- **呼び出し方:** `左の値 == 右の値`
- **引数:** 右側に比較したい値を置きます。今回の右側は `string.reverse` が返した文字列です。
- **戻り値:** 等しければ `true`、異なれば `false` です。
- **この問題での役割:** 元の文字列と逆順の文字列が一致するか判定します。`if` はこの真偽値を使って分岐します。

## `puts`：答えを1行出力する

- **呼び出し方:** `puts 値`
- **引数:** 出力したい値。今回は `"YES"` または `"NO"` を渡します。
- **戻り値:** `nil`。画面への出力が目的のメソッドです。
- **この問題での役割:** 判定結果を改行付きで出力します。

## Rubyらしい書き方のアドバイス

`if` と `else` で両方の場合を明示できていて、今の解答は読みやすいです。入力が必ずある条件を使うなら、次のように `to_s` を省けます。

```ruby
text = gets.chomp

if text == text.reverse
  puts "YES"
else
  puts "NO"
end
```

`string` という名前でも動作します。`text` や `input` にすると、入力した文字列を表していることが少し伝わりやすくなります。`reverse` は元の文字列を変えないため、別の変数へコピーする必要はありません。
