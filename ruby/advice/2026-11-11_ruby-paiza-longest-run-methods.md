# Paiza風問題 10：使用メソッドとRubyらしい書き方

[問題26の解答](../26_paiza風_同じ文字の最長連続/answer.rb)で使ったメソッドを説明します。

## `gets`：標準入力から1行読む

- **引数:** 今回は渡しません。
- **戻り値:** 入力された1行を表す文字列。通常は末尾の改行を含みます。入力がなければ `nil` です。
- **今回の役割:** 調べる文字列を受け取ります。

## `chomp`：行末の改行を取り除く

- **呼び出し方:** `gets.chomp`
- **引数:** 今回は渡しません。引数を指定すると、取り除く行末の区切り文字列を変えられます。
- **戻り値:** 行末の改行を除いた新しい文字列。元の文字列は変更しません。
- **例:** `"abc\n".chomp` は `"abc"` を返します。

## `each_char`：文字を1つずつ処理する

- **呼び出し方:** `string.each_char do |char| ... end`
- **引数:** 通常の引数はありません。ブロックへ1文字ずつ渡します。
- **戻り値:** ブロックを付けた場合は元の文字列。ブロックがなければ `Enumerator` を返します。
- **今回の役割:** 文字を先頭から順に調べ、直前の文字と比較します。

## `puts`：結果を出力する

- **引数:** 出力したい値。今回は最大の連続回数です。
- **戻り値:** `nil`。整数を表示し、末尾に改行を付けます。

## Rubyらしい書き方のアドバイス

今の解答は、直前の文字、現在の長さ、最大の長さを分けて管理できています。次の2点を直すと意図がより伝わります。

- `current_length` は後で `+= 1` する数値なので、最初から `0` にします。`""` は文字列で、連続回数を表す値としては不自然です。
- `previous_char` は最初に実在しない文字を表せればよいので、`nil` も使えます。現在の `""` でも英小文字の入力とは一致しないため、動作は正しいです。

初期値だけを直すなら、次のように書けます。

```ruby
previous_char = nil
current_length = 0
max_length = 0
```

`if current_length > max_length` の比較を毎回行うことで、最長のグループが文字列の最後に来る場合も正しく記録できています。
