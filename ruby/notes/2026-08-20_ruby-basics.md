# Ruby 学習ログ

**学習日:** 2026-08-20
**テーマ:** 変数・文字列・条件分岐の基礎

## 学んだこと

- 変数には文字列や数値を代入できる
- `puts` を使うと、値を画面に表示できる
- `#{変数名}` をダブルクォーテーションの文字列内に書くと、変数の値を埋め込める
- 複数の変数を組み合わせて、自己紹介やあいさつ文を作れる
- `if` と `elsif` を使うと、条件に応じて表示する内容を切り替えられる
- `>=` や `<` を使って、年齢や点数を比較できる

## つまずいた点・気づき

- 文字列への変数の埋め込みは、ダブルクォーテーションを使う必要がある
- Rubyでは、全角スペースがあると `puts` などのメソッド名として認識されない
