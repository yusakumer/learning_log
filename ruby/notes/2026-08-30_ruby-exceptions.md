# Ruby 学習ログ

**学習日:** 2026-08-30
**テーマ:** 例外の発生と捕捉

## 学んだこと

- 想定外の状態では、例外を発生させて呼び出し元へ知らせられる
- 例外の種類とメッセージを指定できる
- 例外を捕捉すると、エラー内容を表示しつつプログラムを続行できる
- エラーが起きる可能性のある処理と、その後に必ず実行したい処理を分けて書ける

## つまずいた点・気づき

- `divide` の通常時の計算と、0で割る場合の例外発生は最初から正しく実装できていた。
- 最初の問題2では、割り算の結果を `5` だけ表示しており、要求された `10 ÷ 2 = 5` という形式になっていなかった。値だけでなく、指定された出力形式も仕様として確認する必要がある。
- 最初の問題2では、例外を捕捉した後に `処理を終了します。` を表示していなかった。例外処理の目的である「エラー後も処理を続ける」を満たすため、例外処理の外に続きの処理を置く必要があった。
- `rescue ZeroDivisionError => e` と例外の種類を限定しているため、対象のエラーが明確になっている。
- `raise ZeroDivisionError,"0では割れません。"` と `a/b` は正しく動作する。`,` や `/` の前後に半角スペースを入れると、コード全体の見た目が揃って読みやすくなる。
