# Ruby 学習ログ

**学習日:** 2026-08-31
**テーマ:** クラスとインスタンス

## 学んだこと

- クラスは、関連するデータと処理をまとめるための設計図として定義できる
- `Person.new` のようにクラスからインスタンス（オブジェクト）を作成できる
- `initialize` はインスタンス作成時に実行され、受け取った値の初期設定に使える
- `@name` や `@age` のようなインスタンス変数で、オブジェクトごとの状態を保持できる
- インスタンスメソッドは、保持している状態を使って自己紹介文を返したり、カウントを更新したりできる
- `Counter` では `increment` で状態を変更し、`value` で現在の値を取得できる

## つまずいた点・気づき

- `Person` と `Counter` を別々のクラスにすることで、それぞれの役割と状態を分けて考えられた
- `Counter` の現在値はローカル変数ではなくインスタンス変数にすることで、メソッドをまたいで保持できる
- 出力では値だけでなく、問題で指定された文字列の形式まで確認することが大切
