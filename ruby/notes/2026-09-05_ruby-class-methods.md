# Ruby 学習ログ

**学習日:** 2026-09-05

## 学んだこと

- `def self.メソッド名` で、クラスから直接呼び出せるクラスメソッドを定義できる
- `Temperature.celsius_to_fahrenheit(25)` のように、インスタンスを作らずに処理を呼び出せる
- `@@count` のようなクラス変数を使うと、すべてのインスタンスで共有する値を管理できる
- `initialize` でインスタンス作成ごとにカウントを増やし、`User.count` で合計を取得できる

## つまずいた点・気づき

- 計算結果やカウントが正しくても、指定された出力文まで一致しているか確認する必要がある
- 出力を修正し、`登録ユーザー数: 2人` の形式を満たせた
