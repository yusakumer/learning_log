# Ruby 学習ログ

**学習日:** 2026-11-11
**テーマ:** Paiza風問題：同じ文字の最長連続

## 学んだこと

- `each_char` で文字を順に調べ、直前の文字と比較できる
- 同じ文字なら現在の連続回数を増やし、違えば `1` に戻せる
- 各文字を処理するたびに最大の連続回数を更新できる

## つまずいた点・気づき

- `tally` は文字ごとの総出現回数を数えるため、連続回数を求める問題にはそのまま使えない
- `current_length` は繰り返しの前に `""` で初期化しても今回の入力では動くが、数値を入れる変数なので `0` にすると型と役割が明確になる
- `aaabbccccd`、`abc`、`a`、`ababa` で期待どおりの結果を確認できた
