# 01 型付き関数：商品の合計金額

## お題

商品の単価と個数を受け取り、合計金額を返す `calculateTotal` 関数を作成してください。

- `price` と `quantity` の型をそれぞれ `number` にします。
- 関数の戻り値の型も `number` と明示します。
- 単価120円、個数3個で関数を呼び出し、結果を指定の形式で表示します。

## 入力例

```text
単価: 120円
個数: 3個
```

## 期待する出力例

```text
合計: 360円
```

## ヒント

- 引数の型は `引数名: 型` の形式で付けます。
- 戻り値の型は引数リストの閉じ括弧の後に指定します。
- 表示には `console.log` とテンプレート文字列を使えます。
