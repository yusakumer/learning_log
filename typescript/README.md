# TypeScript 学習

JavaScriptの書き方を土台に、型を付けて意図を明確にする練習をします。

## 進め方

1. `problem.md` を読む
2. 同じフォルダの `answer.ts` に解答を書く
3. TypeScriptの実行・型チェックができる練習用環境で結果を確認する
4. 解答後にレビューを受ける

このリポジトリには、まだTypeScriptの実行環境を設けていません。問題文と解答ファイルだけを置いています。
